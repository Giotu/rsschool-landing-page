# Project: Landing Page

**Landing Page** is a training project in which you will create a responsive two-page website and add interactivity using vanilla JavaScript.

The assignment consists of two parts, each designed to take one week. During the first week, you will build the semantic, responsive layout and implement a light/dark theme toggle that saves the user's preference. In the second week, you will add the core interactive features.

Layout: [Coffee House](https://www.figma.com/design/yuc5s9NCc4jENkk5LdFfvX/Coffee-House-2026Q3?node-id=0-1)

---

## General technical requirements

- The markup must be valid, semantic, and responsive.
- The project must display and function correctly in the latest version of Google Chrome.
- Vanilla JavaScript must be used to implement functionality.
- The use of CSS frameworks (e.g., Bootstrap) is not permitted.
- The use of JS frameworks (e.g., React, Angular, or Vue) is not permitted.
- The use of TypeScript is not permitted.
- You may not use pre-existing component or interactivity libraries, including those for sliders, modal windows, or burger menus. All functionality subject to evaluation must be implemented from scratch.
- The use of CSS preprocessors (SASS, SCSS) and modern-normalize is permitted.
- The use of build tools such as Vite or Webpack is permitted; if used, source maps must be enabled.
- The code must be readable and free of minification or obfuscation.
- You may not replace the layout markup—or individual blocks thereof—with screenshots. Images should be used solely as standalone content, such as photographs, illustrations, and icons.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone git@github.com:Giotu/rsschool-landing-page.git
   ```

2. Navigate to the project directory:

   ```bash
   cd rsschool-landing-page
   ```

3. Install dependencies and start the development server:
   - **Install dependencies:**
     ```bash
     npm install
     ```
   - **Run the project locally:**
     ```bash
     npm run dev
     ```
