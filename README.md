# Coffee House — Landing Page

Responsive two-page landing page built as part of the Rolling Scopes School
Fullstack Engineering course.

Layout: [Coffee House](https://www.figma.com/design/yuc5s9NCc4jENkk5LdFfvX/Coffee-House-2026Q3?node-id=0-1&p=f)

## Tech Stack

- HTML5
- CSS
- JavaScript
- Vite
- modern-normalize
- ESLint
- Stylelint
- Prettier
- Husky

## Features

- Responsive layout (1440px–380px)
- Light/dark theme
- Theme persistence with localStorage
- Burger menu
- Slider
- Product/category filtering
- Product modal
- Dynamic product options and price calculation

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```
